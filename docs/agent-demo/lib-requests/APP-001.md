# APP-001: RubyLLM 1.16 cannot combine OpenAI tools with medium reasoning

状態: open
担当: /root/lib_fixes（契約確認） /root/sample_app（依存・runner統合）
アプリをブロックするか: yes（`POST /chat/ruby_llm` の指定モデル・mediumによるlive成功）
SDK/model/呼び出し条件: RubyLLM 1.16.0、OpenAI、`gpt-5.6-luna`、`with_tools`、`with_thinking(effort: :medium)`、streaming
最小再現・コマンド: `cd examples/rails_demo && bin/rails runner script/verify_agent.rb ruby_llm`
期待: RubyLLMがResponses APIを使い、function tool loopとmedium reasoningをstreamする。
実際: OpenAI APIが400を返す。RubyLLM 1.16は `/v1/chat/completions` 固定で、同endpointではfunction toolsと`reasoning_effort`を併用できない。失敗runは `status=error`、cacheには保存されていない。
secret除去した証拠: OpenAI errorは “Function tools with reasoning_effort are not supported ... use /v1/responses” 。API key・authorizationは出力していない。
必要な契約/修正案: RubyLLM 2.0開発版のResponses protocolを採用可能か、既存`AgentStream::Adapters::RubyLLM`が新しいchunk/message契約へ対応するか確認する。モデルまたはreasoningの黙った変更は不可。
修正ファイル・互換性: app側のGemfile/runner、必要ならlib adapter。1.16向け既存adapter回帰を維持する。
回帰テスト・結果: 1.16のadapter multi-stepテストはlib担当側で成功済み。実APIだけ上記制約で失敗。
アプリ担当への通知: 2026-09-05 JSTに実APIで発見。RubyLLM公式の2.0開発版upgrading docsはOpenAI Responsesを既定にしてこの組み合わせを可能にすると明記。
